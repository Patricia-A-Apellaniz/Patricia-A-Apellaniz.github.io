What to notice

Try another angle.

Change the threshold to see the trade-off between detecting unusual examples and flagging ordinary ones. Switch applications, then introduce a sensor shift without recalibrating.

What’s actually running here?

A diagonal standardized-distance detector is fitted to 120 ordinary reference observations; it flags new points whose Euclidean distance in z-score coordinates exceeds the threshold. The 240 test labels are invented, with approximately 20% deliberately shifted examples. The wearable and battery cases are affine transformations of the same latent simulation, so normalized distances and decisions match by construction, not because transfer has been validated on real data. Sensor shift moves all test observations by 1.5 reference population standard deviations on each raw axis. No clinical diagnoses, battery failure thresholds, or safety decisions are implied.
