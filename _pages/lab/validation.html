What to notice

Try another angle.

Start with shuffle_y_only. Each column has exactly the same values, but rows are paired differently. Then compare a generator that samples the joint distribution.

What’s actually running here?

The reference has 200 bivariate normal observations with unit population variances and the selected correlation. Shuffling permutes only y and preserves the empirical marginal values exactly. Joint sampling creates new independent observations from the same known simulation; reversal changes the correlation sign. Marginal distance is one-dimensional empirical Wasserstein-1 in feature units. A simple linear regression is fitted separately to reference and synthetic data and tested on the same 1,000 independently simulated reference-distribution observations. MSE and correlation check only specific properties, not complete validity or suitability for every use.
