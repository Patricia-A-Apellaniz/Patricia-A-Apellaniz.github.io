What to notice

In FedAvg, training records stay at each hospital; model parameters travel. That alone is not a privacy guarantee. Here, all hospitals are simulated in this browser — no real patient data or network training.

Same algorithm. Different populations.

Try equal hospital sizes. Then increase the population difference. Look at Hospital C as well as the overall score. Finally, compare 1 local step with 20: fewer exchanges can mean more local drift.

What’s actually running here?

Binary logistic regression on 480 invented training examples split across three hospitals. Population difference changes class proportions and shifts the second feature; the first feature keeps a common class signal. The federated model uses full-participation, sample-size-weighted FedAvg, with full-batch local gradient descent (learning rate 0.3, weight regularization 0.005). Centralized training pools all training rows as a reference; local models see only their own rows. All methods start at zero and take the same number of gradient steps per round, though each step uses different data. Features use fixed scales, not pooled patient statistics. Results are specific to this simple simulation, not a clinical benchmark.
