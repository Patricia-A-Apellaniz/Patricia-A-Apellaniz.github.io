What to notice

Make it earn its score.

Swap the backgrounds. Then disable the background feature, retrain, and test again. You may lose a little familiar-environment accuracy, but gain stability.

What’s actually running here?

Binary logistic regression, fitted locally with gradient descent on 800 invented examples. Each example has a true class, a noisy shape score and a binary background code. Inputs are standardized using training statistics. Each evaluation uses 600 separate examples; the shape scores and labels stay fixed across environments while background codes change. All results are computed from the fitted model. The displayed shapes illustrate the noisy shape cue; this is not an image classifier or a clinical model.
